    🎯 1. Project Overview

    Smart Classroom is a comprehensive web-based Learning Management System (LMS) built with Django that connects admins, teachers, and students in a digital classroom environment. It includes 12 Django apps and 24 database models.

    Feature Summary

    # Feature Description
    1 User Management 3 roles (Admin, Teacher, Student) with approval workflows
    2 Department & Course Management Departments → Courses with unique codes, approval system
    3 Enrollment System Students request enrollment → Teacher/Admin approves
    4 Assignments Create, submit (file/GitHub), grade with marks & feedback
    5 Quizzes MCQ-based quizzes with auto-scoring, time limits, date windows
    6 Online Coding Tests In-browser coding IDE with sample/hidden test cases, auto-evaluation
    7 Attendance Teacher marks or student self-marks (with deadlines)
    8 Study Materials Upload PDF, DOC, PPT, ZIP, PY files for download
    9 Recorded Classes Video uploads (file or URL) with streaming player
    10 Team Projects Project submissions with GitHub links, ZIP uploads, grading
    11 Chat System 1-on-1 direct messages + per-course group chat (AJAX real-time)
    12 AI Tutor Per-course AI chatbot powered by Google Gemini
    13 Virtual Sessions Schedule online meeting links with auto-attendance
    14 Certificates Issue badges (Completion, Excellence, Topper, Participation)
    15 Reports & Leaderboard Report cards, grade exports (CSV/Excel), rankings
    16 Notification System In-app notifications for all key events
    17 Admin Panel Custom admin dashboard for managing everything
    18 Light/Dark Mode CSS variable-based theme toggle

    6.2 Entity Relationship Diagram (Partitioned by Module)

    To ensure readability and clarity, the massive 24-model database schema has been divided into 7 logical modules.

    6.1.1 Module 1: User Profiles & Direct Messages

    Manages registration status, authentication roles, in-app notifications, and direct messaging between users.

    6.1.2 Module 2: Course & Enrollment Structure

    Handles departments, courses, student enrollment requests, virtual live sessions, per-course group chats, and AI Tutor logs.

    6.1.3 Module 3: Study Materials & Recorded Classes

    Stores uploaded files (PDFs, PPTs, code files) and recorded video links/files for course materials.

    6.1.4 Module 4: Assignments & Project Management

    Organizes standard assignments (with grade + feedback) and capstone team project submissions.

    6.1.5 Module 5: Quiz Assessment System

    Represents MCQ-based quizzes, questions, options (choices), attempts, and student answers.

    6.1.6 Module 6: Online Coding Tests

    Details the coding exam engine, including questions, test cases (sample/hidden), and execution evaluation scores.

    6.1.7 Module 7: Attendance, Grading & Certificates

    Manages student attendance tracking, issued completion/excellence badges, and aggregated report cards.

    📝 8. Step-by-Step: How to Create a Course (Example)

    Scenario

    Teacher "Dr. Sharma" wants to create a course called "Machine Learning Fundamentals" under the Computer Science department and invite students.

    Step 1: Login as Teacher

    1. Open browser → Go to http://localhost:8000
    2. Redirected to /users/login/
    3. Enter credentials: teacher1 / pass123
    4. Click Login → Redirected to Teacher Dashboard

    Step 2: Create the Course

    1. Click "Create Course" on the dashboard
    2. Navigate to /courses/create/
    3. Fill in the form:
    Field Example Value
    Title Machine Learning Fundamentals
    Description Learn the basics of ML including regression, classification, clustering, and neural networks.
    Department Computer Science
    Max Students 50
    Start Date 2026-06-15
    End Date 2026-09-15
    Project Start 2026-08-01
    Project End 2026-09-10
    Cover Image Upload a banner image
    1. Click Submit

    [!IMPORTANT] The course is created with approval_status = pending. An Admin must approve it before students can see it. The system auto-generates a unique course_code (e.g., CS-ML2026) and batch identifier.

    Step 3: Admin Approves the Course

    1. Admin logs in → Goes to Admin Panel → Courses
    2. Sees the pending course → Clicks Approve
    3. Course is now visible to students

    Step 4: Students Enroll

    1. Student logs in → Browses Departments → Clicks Computer Science
    2. Sees "Machine Learning Fundamentals" in the course list
    3. Clicks the course → Sees the About page
    4. Clicks "Enroll" → Enrollment request created (status = pending)
    5. Teacher gets notification: "Student X requested enrollment"
    6. Teacher clicks Approve → Student now has full access

    Step 5: Add Content to the Course

    After enrollment, the teacher adds content from the Course Detail page:

    Action What Teacher Does What Students See
    Create Assignment Title: "Linear Regression", Due: June 25, Marks: 100, Attach PDF Assignment appears in course + dashboard "Pending"
    Upload Material Upload "ML_Notes.pdf" (type: pdf) Material available for download
    Create Quiz Title: "ML Basics Quiz", Duration: 30 min, Add 10 MCQs Quiz appears in dashboard "Upcoming"
    Create Coding Test Title: "Implement KNN", Time: 60 min, Add coding question + test cases Test appears in course detail
    Upload Recording Upload lecture video file or paste YouTube URL Recording available in course
    Schedule Virtual Session Set meeting link + date/time Session listed, auto-attendance created
    Open AI Tutor Available immediately per course Students can chat with AI about course topics

    Step 6: Student Submits Assignment

    1. Student opens Assignment Detail → Clicks Submit
    2. Uploads a .py file OR pastes a GitHub link
    3. System enforces hard deadline (server-side check)
    4. Submission saved with timestamp

    Step 7: Teacher Grades

    1. Teacher opens Assignment Detail → Sees all submissions
    2. For each student, enters:
    3. Grade: 85 (out of 100)
    4. Feedback: "Good implementation, but missing edge case handling."
    5. Clicks Save → Student gets notification: "Your assignment scored 85/100"

    Step 8: End of Course

    Action Result
    Generate Report Cards Score summary per student (assignments + quizzes + tests)
    Export to Excel Color-coded spreadsheet with all marks + weekly analysis
    Issue Certificates Select badge type per student (Completion/Excellence/Topper)
    Release Results Toggle results_released → students can see all scores

    🤖 9. AI Integration

    AI Tutor (Per-Course Chatbot)

    Property Detail
    Model Google Gemini (via google-generativeai library)
    URL /courses/<course_pk>/ai-tutor/
    How it works AJAX-based chat. Conversation history saved in AITutorMessage model. Supports different actions (general, topic-specific).
    Persistence Full conversation saved per user per course
    Fallback If API key missing, shows demo mode

    Coding Test Evaluation Engine

    Property Detail
    Function evaluate_coding_question() in tests app
    Process Takes student code → runs against hidden test cases → compares output
    Scoring Weighted test cases, partial credit possible
    Security Server-side execution only
